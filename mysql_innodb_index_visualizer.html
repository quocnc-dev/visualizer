Trực quan hóa Clustered vs Secondary Index & Phân bổ file user.ibd

1. Clustered Index (Primary Key)

Là cây chính chứa **TOÀN BỘ DỮ LIỆU**. Nút lá lưu mọi cột (id, name, email, address...). Dung lượng 1 bản ghi rất lớn (~600 Bytes).

2. Secondary Index (Chỉ mục phụ)

Cây phụ dựng song song. Nút lá chỉ lưu gọn nhẹ các cột Index + **Primary Key** để trỏ về cây chính. Dung lượng rất nhỏ (~45 Bytes).

3. Trang Bộ Nhớ (16KB Pages)

Cả 2 cây Index đều được lưu chung trong file `.ibd`. Ổ đĩa được chia thành các khối **16KB**. Cây phụ gọn nhẹ nên tốn ít Trang (Pages) hơn!
